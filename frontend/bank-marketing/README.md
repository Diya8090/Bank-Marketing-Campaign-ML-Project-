# Bank Marketing Frontend — Term Deposit Subscription Predictor

React 19 & Vite frontend workspace for the Bank Marketing Campaign Machine Learning project.

## Scripts
- `npm run dev`: Starts local Vite development server at `http://localhost:5173`
- `npm run build`: Compiles production build to `dist/`
- `npm run lint`: Runs ESLint check across all JSX and JS files

## Environment Variables
Copy `.env.example` to `.env`:
```text
VITE_API_URL=http://localhost:8000
```
